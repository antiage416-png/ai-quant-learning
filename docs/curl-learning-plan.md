# curl을 포함한 크롤링 학습 보완안

작성일: 2026-09-18. 기존 24주 계획의 1~4주 크롤링 실습에 통합한다. 학습 시간은 기존 하루 시간 안에서 배분하고, 부족하면 주말 보충 시간에 이어간다.

## 목적

Ubuntu Bash에서 curl로 HTTP 요청·응답을 확인한 뒤 같은 요청을 Python requests 또는 httpx로 옮긴다. 응답 HTML의 항목 추출은 BeautifulSoup, 표 정리는 pandas로 진행한다. curl은 데이터 전송 도구이며 HTML을 자동으로 분석하거나 브라우저처럼 JavaScript를 실행하는 도구는 아니다.

## 수업 진행 원칙

한 번에 명령 하나를 설명하고 결과를 확인한다. 실행 환경은 VS Code의 WSL: Ubuntu 터미널이다. 목적·옵션·예상 결과와 파일 변경 여부를 명시한다. 명령을 무조건 외우기보다 요청을 읽고 설명하는 것을 목표로 한다.

첫 확인 명령은 다음과 같다. 네트워크 요청이나 설치·파일 변경은 없다.

```bash
# 설치된 curl의 버전과 지원 기능을 확인합니다.
# --version은 버전 정보를 출력하는 옵션입니다.
curl --version
```

버전 정보가 나오면 설치된 상태다. command not found가 나오면 설치 단계를 따로 안내한다.
