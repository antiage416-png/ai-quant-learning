# 매일 학습하고 저장하기

## 수업 시작
1. 사용할 컴퓨터와 오늘 진행할 계획표 일차를 확인합니다.
2. GitHub 연결 후에는 저장소에서 `git status`를 확인합니다.
3. 미저장 변경이 없다면 `git pull --ff-only`로 다른 PC의 기록을 가져옵니다.
4. templates/daily-log.md를 daily/YYYY-MM-DD.md로 복사합니다. 같은 날 파일이 있으면 이어서 작성합니다.

## 수업 진행
개념을 짧게 배우고 한 가지 실습을 실행합니다. 출력과 오류를 확인한 뒤 다음 단계로 넘어갑니다.
기록은 실제 실행한 내용만 남깁니다. 질문과 이해하지 못한 부분도 기록합니다.

## 수업 종료
1. 오늘의 목표와 검증 결과를 정리합니다.
2. `git diff`로 변경 내용을 읽습니다.
3. PowerShell에서 `./scripts/save-learning.ps1`를 실행해 변경 내용을 커밋합니다.
4. 사용자가 직접 `git push`를 실행해 GitHub에 업로드합니다. 최초에도 upstream이 설정되어 있으면 같은 명령을 사용합니다.
5. 실패하면 오류를 해결한 뒤 다시 실행합니다. GitHub 웹에서도 커밋과 파일을 확인합니다.

스크립트는 정해진 폴더만 추가하며 비밀 파일 이름·일부 토큰 형태·큰 파일을 검사합니다.
모든 민감정보를 발견하는 보안 도구는 아니므로 업로드 내용을 직접 확인해야 합니다.
GitHub 인증과 원격 주소가 준비되지 않았다면 -Push 없이 로컬 커밋만 사용합니다.

## 두 컴퓨터 사용
두 번째 PC에서는 같은 저장소를 clone합니다. 한 PC에서 종료 시 push, 다른 PC에서 시작 시 pull 순서를 지킵니다.
충돌이 나면 자동 저장을 중단하고 변경 내용을 비교합니다. 강제 push나 자동 reset으로 해결하지 않습니다.
Python 가상환경과 비밀키는 각 컴퓨터에서 따로 준비합니다.

## 자동 실행
현재 제공하는 스크립트는 실행했을 때 커밋·업로드합니다.
GitHub 업로드는 사용자가 직접 실행합니다. 정기 자동 커밋은 아직 예약하지 않았습니다.
예약 실행은 실행 장치·인증·네트워크 사용 가능 여부에 영향을 받으며, 실패 기록을 확인해야 합니다.
