# 한국 주식 AI 퀀트·에이전트 개발: 24주 일별 행동계획표

시작일 미정이므로 각 주의 1~5일차는 평일, 6~7일차는 주말로 표기했습니다. 첫 학습 주의 월요일을 1일차로 잡으면 됩니다.

## 학습 전제

- pandas는 이해하고 있으며 필요한 문법은 찾아서 사용합니다.
- 평일 하루 3시간, 주말 하루 4시간을 가정합니다. 주 23시간, 24주 약 552시간의 계획이며 숙련을 보장하는 기간은 아닙니다.
- PC 1: i7-11700, RAM 16GB, Intel UHD Graphics 750, Windows 10 Home 22H2(기존 기록 기준). PC 2: i5-7300HQ, RAM 8GB, GTX 1050 2GB, Windows 10 Pro 22H2(2026-09-17~18 확인). 저장 공간과 설치 상태는 [환경표](environments.md)를 기준으로 확인하며, 각 PC의 설치 가능 여부와 자원 사용량에 맞춰 환경을 정합니다.
- 대상은 한국 주식의 일봉 데이터, 공시, 분석 보고서와 모의투자입니다. 실거래는 이 계획에 포함하지 않습니다.
- 저장소는 참고 교재로 활용합니다. 앞서 확인한 소개·일부 README를 기반으로 한 계획이며, 각 실습 시점에 최신 README·의존성·공식 문서·이용 조건을 다시 확인합니다.
- 클라우드 예산은 아직 미정입니다. 17주차에 먼저 정하고, 예산이 없으면 같은 배포 과제를 로컬에서 계속합니다.

## 하루 운영 방식

평일: 개념 30분 → 구현 100분 → 검증·오류 해결 30분 → 학습 기록과 Git 커밋 20분.

주말: 복습 30분 → 통합 구현 140분 → 검증 40분 → 정리 30분. 매주 7일차는 미완료 작업 보충을 우선합니다. 주말에도 3시간만 가능하면 미완료 작업을 이월하고 전체 기간을 늘립니다.

매일 날짜·목표·실행 명령·결과·오류 원인·다음 행동을 기록합니다. 완료 기준을 충족하지 못하면 이후 주차를 억지로 진행하지 않고 7일차에 보충합니다. 두 PC에서는 동일한 Git 커밋·의존성·데이터 샘플로 재현하되 키와 비밀값은 공유 저장소에 올리지 않습니다.
