# 8주차 53일차 — 백테스트 실행·결과 조회 API

## 목적과 흐름

- POST /api/backtests: 새 계산 → 새 실행 ID → JSON 저장 → 결과 반환.
- GET /api/backtests/{run_id}: 해당 ID의 저장 파일을 읽어 반환.
- 실행 API는 삼성전자 005930의 2025년 전체 기간 교차 전략으로 고정돼 있다.
- 요청에서 종목·기간·전략을 변경하는 기능은 아직 없다.

## 기존 계산 조건

44일차의 입력 읽기·비용 설정·계산·장부 검사·요약 함수를 재사용한다.

- 가격: data/stock-day33/clean/005930_2025_clean.csv
- 주문: data/stock-day40/005930_2025_signals.csv
- 초기 자금: 10,000,000원.
- 기존 수수료·세금·슬리피지와 최대 정수 매수·전량 매도를 유지한다.
- 주문은 이미 다음 거래일에 배치돼 있으므로 다시 이동하지 않는다.
- 마지막 보유분은 종가로 평가하며 강제 매도하지 않는다.

## 저장 방식

- 실행마다 uuid4로 새 ID를 만든다.
- 결과: data/stock-day53/runs/{run_id}.json
- ID 연습 기록: data/stock-day53/id_practice/
- 실제 결과에는 ID·종목·기간·행 수·비용 설정·계산 요약을 저장한다.
- Decimal 금액과 비율은 정확한 값을 보존하도록 문자열로 저장한다.
- 파일 생성은 x 모드로 기존 파일 덮어쓰기를 거절한다.

## 확인한 결과

- ID 생성, 저장 함수 분리, JSON 저장·재읽기 비교를 확인했다.
- 가격·주문 각 242행, 2025-01-02~2025-12-30을 확인했다.
- 가격·주문의 거래일과 전날 날짜·신호 연결 검사가 통과했다.
- 장부 242행, 현금·수량·비용 연결 검사가 통과했다.
- 최종 자산: 16,319,889.65원.
- 기간 수익률: 63.1988965%.
- 최종 자산과 수익률은 기존 44일차 결과와 일치했다.
- POST의 201 응답과 새 ID 발급을 확인했다.
- 새 실행 ID: f89ffd3d-38ea-40e6-81a9-d3ebb2d67f11
- 서버 재시작 후 같은 ID의 GET 조회와 저장 내용 유지가 확인됐다.

## 범위와 다음 보완

- 저장된 기존 신호·주문을 사용하며 이동평균을 새로 계산하지 않는다.
- 저장하는 것은 계산 요약이며 일별 장부 전체는 저장하지 않는다.
- 원본 자료와 기존 44일차 결과 파일은 갱신하지 않는다.
- 45일차 미체결 취소 규칙을 전체 계산에 통합한 것은 아니다.
- 기존 전체 기간 성과를 이미 봤으므로 독립적인 미관측 평가로 해석하지 않는다.
- 누락·손상 자료, 잘못된 ID와 없는 결과의 오류 응답 검증은 후속 과제다.
- 실행 확인과 독립적인 구현 숙련도는 구분한다.
