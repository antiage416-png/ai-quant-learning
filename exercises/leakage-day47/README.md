# 7주차 47일차 — 미래 자료 추가 전후의 과거 신호 불변 검사

## 목표와 검사 방법

미래 자료를 추가해도 이전 시점의 이동평균과 교차 신호가 바뀌지 않는지 확인한다.
전체 결과를 잘라 비교하는 것만으로 끝내지 않고, 입력 자체를 각 시점까지 잘라
이동평균·신호를 처음부터 다시 계산한 뒤 전체 계산의 같은 과거 구간과 비교했다.

## 유지한 계산 규칙

- 현재까지의 종가로 5일·20일 이동평균을 계산한다. 초기 결측은 각각 4행·19행이다.
- 오늘과 전날의 두 이동평균이 모두 있어야 교차를 판단한다.
- 전날 5일선이 20일선 이하이고 오늘 위로 올라가면 골든크로스다.
- 전날 5일선이 20일선 이상이고 오늘 아래로 내려가면 데드크로스다.
- 오늘 두 선이 같으면 교차 신호가 없다. 전날 신호는 `shift(1)`로 연결한다.
- 40일차의 교차·동률·초기 결측 조건을 검증용 함수로 옮겼으며 기존 프로그램은 실행하지 않았다.
- 체결·수량·비용·수익률을 계산하거나 기존 조건을 변경하지 않았다.

## 작은 예제의 실제 결과

- 예제 35행: 골든크로스 2회·데드크로스 1회.
- 앞 20행부터 34행까지 15개 지점에서 정상 계산의 과거 결과 변화는 0개였다.
- 의도적으로 `shift(-1)`로 다음 날 신호를 가져온 잘못된 계산은 3개 지점에서 변화가 탐지됐다.
- 잘못된 계산의 2025-03-31 신호는 앞 20행만 있을 때 없음,
  전체 35행을 넣었을 때 골든크로스로 바뀌었다.
- 초기 결측·동률 이후 교차·전날 신호 연결·입력 보존 검사가 통과했다.
- 예제의 날짜와 가격은 검증용이며 실제 삼성전자 시세가 아니다.

## 실제 자료의 확인된 결과

| 항목 | 결과 |
|---|---|
| 대상 | 삼성전자 005930, KRX |
| 기간 | 2025-01-02 ~ 2025-09-30 |
| 입력 | 개발 118행 + 검증 65행 = 183행 |
| 기존 결과 대조 | 40일차 앞 183행의 이동평균·마감 신호·전날 신호와 일치 |
| 재계산 지점 | 앞 20행부터 182행까지 163개 |
| 과거 결과 변화 | 0개 지점 |
| 개발 구간 경계 | 개발 118행과 전체 183행의 같은 과거 구간 일치 |
| 입력 보존 | 입력 표·파일 보존 검사 통과 |
| 최종 평가 CSV | 읽지 않음 |

기존 CSV의 이동평균과 비교할 때는 저장·재읽기로 생길 수 있는 작은 실수 표현 오차만 허용했다.
문자열 신호는 정확히 비교했고, 입력 길이를 달리한 재계산 결과끼리는 결측 위치와 숫자·신호를 정확히 비교했다.

## 실행과 결과 파일

Ubuntu의 기존 가상환경에서 실행한다.

```bash
# 기존 가상환경을 활성화합니다.
source /home/jaeho/ai-quant-learning/.venv/bin/activate

# 작은 예제로 정상 계산과 미래 신호 사용 탐지를 검사합니다. 파일 저장은 없습니다.
python /home/jaeho/ai-quant-learning/exercises/leakage-day47/check_prefix.py

# 개발·검증 자료를 검사하고 보고서와 로컬 요약을 저장합니다.
python /home/jaeho/ai-quant-learning/exercises/leakage-day47/verify_prefixes.py
```

- 입력 CSV: `/home/jaeho/ai-quant-learning/data/stock-day46/development/005930_2025_clean.csv`와
  `/home/jaeho/ai-quant-learning/data/stock-day46/validation/005930_2025_clean.csv`.
- 기존 대조 자료: `/home/jaeho/ai-quant-learning/data/stock-day40/005930_2025_signals.csv`의 앞 183행.
- 검사 보고서: `/home/jaeho/ai-quant-learning/exercises/leakage-day47/prefix_report.md`.
- 로컬 요약: `/home/jaeho/ai-quant-learning/data/stock-day47/prefix_summary.json`.
- 같은 결과로 재실행하면 기존 출력을 유지한다. 내용이 다르면 확인을 위해 중단한다.
