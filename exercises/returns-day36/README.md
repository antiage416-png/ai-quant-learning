## 36일차 — 단순수익률과 누적수익률

### 학습 목표

직전 가격 대비 단순수익률과 처음 가격 대비 누적수익률을 구분하고,
손계산 예제와 실제 삼성전자 종가에 적용한다.

### 계산 원리

- 단순수익률 = 현재 가격 / 직전 가격 - 1
- 누적수익률 = 현재 가격 / 기준 가격 - 1
- 누적수익률은 각 기간의 (1 + 단순수익률)을 누적해서 곱한 뒤
  1을 빼는 방법으로도 계산할 수 있다.
- 수익률을 단순히 더한 값은 일반적으로 누적수익률과 다르다.

### 작은 예제의 실제 결과

가격 100 → 110 → 99를 사용했다.

- 단순수익률: 첫날 NaN, 둘째 날 +10%, 셋째 날 -10%
- 단순수익률 합: 0%
- 최종 누적수익률: -1%
- 단순수익률 손계산 비교: 통과
- 누적수익률 두 계산법 비교: 통과
- 최종 누적수익률 손계산 비교: 통과

첫날의 단순수익률은 비교할 이전 가격이 없어 NaN이다.
첫날을 기준으로 하는 누적수익률은 0%다.

### 실제 데이터와 결과

- 입력: data/stock-day33/clean/005930_2025_clean.csv
- 공급원: 한국투자증권 Open API
- 기존 수집 조건: KRX 일봉, 수정주가 요청값 0
- 사용한 열: 종가(close)
- 전체 가격 데이터: 242행
- 계산 가능한 일간수익률: 241개
- 기준일: 2025-01-02
- 기준일 종가: 53,400원
- 마지막 날짜: 2025-12-30
- 마지막 종가: 119,900원
- 기준일 종가 대비 누적수익률: 124.5318%
- 누적수익률 두 계산법 비교: 통과
- CSV 재읽기 비교: 통과

### 출력 파일과 단위

- 출력: data/stock-day36/005930_2025_returns.csv
- 열: stock_code, market, date, close, daily_return, cumulative_return
- CSV의 수익률은 소수 단위다. 0.01은 1%를 뜻한다.
- 터미널에서는 수익률을 퍼센트로 표시한다.
- 첫날 daily_return은 CSV에서 빈칸으로 저장된다.
- 입력 CSV는 변경하지 않는다.
- 재실행하면 출력 CSV를 갱신한다.

### 해석 범위와 이해 상태

- 일간수익률은 날짜순으로 정렬한 직전 거래일 종가와 비교한다.
- 누적수익률의 기준은 2025-01-02 종가다.
- 전년도 마지막 종가를 기준으로 한 연간 수익률은 계산하지 않았다.
- 매매 비용이나 현금 배당을 별도로 반영하지 않았다.
- 계산의 일관성을 확인한 것이며 원천 가격의 정확성을 새로 검증한 것은 아니다.
- 실행과 결과 확인은 완료했다.
