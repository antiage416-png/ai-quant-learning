# 27일차 — 한국 주식 데이터 제공처 비교

확인일: 2026-09-30
목적: 국내 주식 일별 가격·거래량 수집에 사용할 제공처를 비교한다.

## 비교표

| 항목 | 한국투자증권 | KRX OPEN API | 키움 REST API |
|---|---|---|---|
| 데이터 | 국내주식 기간별시세 | 시장별 일별매매정보 | 주식일봉차트 |
| 확인한 필드 | 날짜, 시가·고가·저가·종가, 거래량·거래대금 | 일별매매정보 제공 확인, 세부 필드 미확인 | 날짜, 시가·고가·저가·현재가, 거래량·거래대금 |
| 수정주가 | 선택 가능 | 해당 API 적용 여부 미확인 | 선택 가능, 기준일에 따른 적용 조건 있음 |
| 준비 | 계좌·ID 연결, API 신청, 키·토큰 | 회원가입, 인증키 및 API별 활용 승인 | 계좌·HTS ID 연결, API 신청, 키·토큰 |
| 호출 제한 | 실전 계좌당 초당 18건, 모의 초당 1건 | 인증키당 하루 10,000회 이하 | 국내주식 조회 계좌·토큰별 초당 5회, 모의는 TR 하나당 초당 1회 |
| 추가 조건 | 신규 신청 후 3일간 초당 3건, 모의 제외 | 인증키 이용기간 1년, 연장 가능 | 실서버 3개월 미접속 시 자동 해지될 수 있음 |
| 데이터 양 | 기간별시세 요청당 최대 100건 | 2010년 이후 데이터 제공 | 연속조회 지원, 요청당 최대 건수 미확인 |
| 비용 | API 기본 무료, 매매 수수료 별도 | API 자체 이용료 미확인, 별도 유료 데이터 상품 존재 | API 자체 이용료 미확인, 매매 수수료는 HTS와 동일 |
| 이용 조건 | 개인은 자기 자산 투자 목적, 제3자 제공 불가 | 비상업적 이용, 제3자 제공 불가, 화면 제작 시 출처 표시 | REST 약관의 재배포 조건 미확인 |
| 판단 | 우선 후보 | 보조 후보 | 비교 참고 |

미확인은 기능이 없거나 무료라는 뜻이 아니다.
키움의 현재가 필드를 종가로 사용할 조건은 실제 구현 전에 확인한다.

## 선택 이유

한국투자증권을 우선 후보로 둔다.
이미 계좌를 사용 중이며 필요한 일별 가격·거래량과 수정주가 선택을 확인했다.
계좌 보유와 API 서비스 신청은 별개이며, API 신청 완료 여부는 아직 확인하지 않았다.

## 이해할 핵심

- 요청당 최대 100건은 데이터 양, 초당 호출 제한은 요청 속도다.
- 제공처마다 필드 이름과 가격 조정 기준이 달라 수집 후 통일해야 한다.
- 무료 조회가 재배포 허용을 뜻하지 않는다.
- 실제 시세 데이터는 코드와 분리해서 관리한다.

## 확인 범위

공식 문서와 공지를 비교했다.
실제 주가 API 호출과 인증키 발급은 이번 작업에서 진행하지 않았다.
호출 제한과 약관은 실제 사용 전에 최신 내용을 다시 확인한다.
