## 37일차 — 이동평균·변동성·거래량 지표

### 학습 목표

최근 여러 거래일을 묶어 지표를 계산하고,
계산에 필요한 관측값이 부족할 때 생기는 초기 결측 구간을 확인한다.

### 작은 예제

- 가격: 100 → 110 → 90 → 120 → 150
- 최근 3개 이동평균: NaN, NaN, 100.00, 106.67, 120.00
- 결측값 2개, 계산된 값 3개
- 초기 결측 구간 및 손계산 비교: 통과

### 실제 데이터와 계산 기준

- 입력: data/stock-day33/clean/005930_2025_clean.csv
- 대상: 삼성전자 KRX 일봉, 2025년
- 기존 수집 조건: 수정주가 요청값 0
- 날짜순으로 정렬한 242행을 사용했다.
- 5거래일 이동평균: 현재 행을 포함한 최근 종가 5개의 평균
- 20거래일 이동평균: 현재 행을 포함한 최근 종가 20개의 평균
- 20개 수익률 변동성: 최근 일간수익률 20개의 표본 표준편차
- 20거래일 거래량 평균: 현재 행을 포함한 최근 거래량 20개의 평균
- 변동성은 ddof=1로 계산하며 연율화하지 않았다.
- rolling의 구간은 달력 일수가 아니라 데이터 행 수 기준이다.

### 실제 결측 구간 검사 결과

| 열 | 초기 결측 개수 | 첫 유효 날짜 |
|---|---:|---|
| daily_return | 1 | 2025-01-03 |
| ma_5 | 4 | 2025-01-08 |
| ma_20 | 19 | 2025-02-04 |
| volatility_20 | 20 | 2025-02-05 |
| volume_ma_20 | 19 | 2025-02-04 |

- 전체 행 수: 242
- 초기 결측 구간 검사: 통과
- CSV 재읽기 비교: 통과
- 초기 구간 이후의 결측값이나 무한대가 없는지 검사했다.
- 결측값을 채우거나 해당 행을 삭제하지 않았다.

### 마지막 거래일 결과

2025-12-30 기준, 화면에 출력된 값이다.

- 종가: 119,900원
- 5거래일 이동평균: 115,800원
- 20거래일 이동평균: 109,120원
- 거래량: 19,746,349주
- 20거래일 거래량 평균: 18,906,125.1주
- 일간수익률: 0.3347%
- 20개 수익률 변동성: 2.2957%

화면에 표시한 소수는 반올림된 값이다.
변동성은 과거 일간수익률의 흩어진 정도이며 미래 변동 범위의 예측값이 아니다.

```bash
python /home/jaeho/ai-quant-learning/exercises/indicators-day37/check_rolling.py

# API 요청이나 입력 CSV 변경은 없습니다.
python /home/jaeho/ai-quant-learning/exercises/indicators-day37/calculate_indicators.py
```

### 출력과 해석상 주의점

- 출력: data/stock-day37/005930_2025_indicators.csv
- 재실행하면 출력 CSV를 갱신한다.
- CSV의 수익률과 변동성은 소수 단위다. 0.01은 1%다.
- 터미널에서는 수익률과 변동성을 100배 해 퍼센트로 표시한다.
- 초기 결측값은 CSV에서 빈칸으로 저장된다.
- 수익률 20개를 계산하려면 가격 21개가 필요하다.
- 당일 종가·거래량을 포함한 지표이므로 해당 값이 확정된 뒤 사용할 수 있다.
- 미래 값으로 초기 결측값을 채우지 않는다.
- 지표 계산은 매매 전략의 성과 검증과 다르다.
- 실행·결과 확인은 완료했으며 이해·숙련도는 별도로 확인해야 한다.
