## 41일차 — 교차 전략과 매수 후 보유 비교

### 학습 목표

두 전략을 같은 기간·초기자금·가격 자료·비용 처리 조건으로 비교하고,
자산가치와 최대낙폭을 함께 해석한다.

### 이번 비교의 의미

- 교차 전략: 골든크로스 확인 후 다음 거래일 시가에 매수하고,
  데드크로스 확인 후 다음 거래일 시가에 전량 매도한다.
- 매수 후 보유 전략: 첫 거래일 시가에 매수하고 종료일까지 보유한다.
- 자산가치는 남은 현금과 보유 주식의 종가 평가액을 합한 금액이다.
- 자산가치 그래프는 돈이 늘거나 줄어든 경로를 보여준다.
- 낙폭 그래프는 그때까지의 고점에서 얼마나 하락했는지 보여주며,
  가장 깊은 지점이 최대낙폭이다.

### 합의한 공통 조건

| 항목 | 조건 |
|---|---|
| 대상 | 삼성전자(005930), KRX |
| 초기자금 | 두 전략 모두 10,000,000원 |
| 비교 기간 | 2025-01-02 ~ 2025-12-30 |
| 매수 수량 | 현재 현금으로 살 수 있는 최대 정수 수량 |
| 잔여 현금 | 유지하며 이자는 계산하지 않음 |
| 매도 수량 | 보유 주식 전량 |
| 거래 가격 | 해당 주문일의 저장된 시가 |
| 일별 평가 | 현금 + 보유 수량 × 당일 종가 |
| 종료 처리 | 마지막 종가로 평가하며 강제 매도하지 않음 |
| 비용·배당 | 비용을 차감하거나 배당금을 별도로 입금하지 않음 |

가격은 기존 수정주가 요청으로 받은 자료를 사용한다.
초기자금 1,000만원은 사용자가 선택했고 나머지 조건도 합의했다.

### 계산 기준

- 누적수익률 = 현재 자산가치 / 초기자금 - 1
- 누적 최고값은 초기자금과 그때까지의 종가 평가액을 함께 고려한다.
- 낙폭 = 현재 자산가치 / 누적 최고값 - 1
- 최대낙폭은 음수로 표시한 낙폭의 최솟값이다.
- 첫날의 손실도 낙폭에 포함한다.
- 교차 전략은 첫 매수 전까지 초기자금을 현금으로 유지한다.
- 40일차 주문 기록은 이미 다음 거래일에 배치돼 있어 다시 이동시키지 않는다.

### 작은 예제 검증

초기자금 1,000만원으로 시가 55,100원에 181주를 매수했다.

- 매수 후 현금: 26,900원
- 첫날 종가 55,900원의 자산가치: 10,144,800원
- 둘째 날 종가 54,000원의 자산가치: 9,800,900원
- 셋째 날 시가 53,300원에 전량 매도한 자산가치: 9,674,200원
- 최종 손익: -325,800원
- 비용 차감 전 수익률: -3.2580%
- 현금·수량·자산가치와 최종 손익·수익률 검사: 통과

### 결과 해석

이번 종목·기간·조건에서는 매수 후 보유가 최종 자산도 높고,
최대낙폭의 크기도 작았다.

매매를 많이 하거나 이동평균 신호를 사용한다는 사실만으로
수익이 높아지거나 낙폭이 줄어드는 것은 아니다.
이번 결과만으로 다른 기간에도 같은 전략이 우수하다고 판단하지 않는다.

38일차의 가격 수익률 +124.5318%는 첫날 종가 53,400원을 기준으로 했다.
이번 기준전략은 첫날 시가 52,700원에 정수 수량을 매수하고
잔여 현금까지 포함해 평가했으므로 수익률이 +127.0080%로 달라졌다.

### 그래프 해석

- 위쪽 파란 선: 교차 전략의 자산가치
- 위쪽 주황 선: 매수 후 보유의 자산가치
- 위쪽 회색 점선: 초기자금 1,000만원
- 아래쪽 두 선: 각 전략의 누적 최고값 대비 낙폭
- 금액은 원 단위이며 낙폭은 퍼센트 단위다.
- 교차 전략의 수평 구간은 주식을 보유하지 않고 현금을 유지한 기간이다.
- 현금 대기 중에도 이전 고점보다 자산이 적으면 낙폭은 음수로 남는다.
