# 33일차 — 여러 종목과 날짜 기준 증분 수집

## 목적
종목별 조회 완료 날짜를 기록하고,
이미 완료한 범위를 다시 요청하지 않는 수집기를 만든다.

## 수집 기준
- 종목: 삼성전자, SK하이닉스, 현대차, NAVER, 신한지주
- 제공처: 한국투자증권
- 시장: KRX
- 기간: 2025-01-01~2025-12-31
- 단위·가격 기준: 일별 수정주가

## 코드 역할
| 파일 | 역할 |
|---|---|
| plan_collection.py | 기존 삼성전자 결과 확인과 최초 수집 계획 출력 |
| collect_incremental.py | 미수집 기간 조회·저장과 완료 상태 갱신 |
| clean_stocks.py | 완료 기록에 연결된 원본을 종목별 CSV로 변환·검증 |
| check_incremental.py | 임시 상태와 대체 함수로 증분 로직 검사 |

32일차의 인증 코드와 열 정의를 가져와 사용하므로
exercises/stock-day32 폴더도 필요하다.

## 완료 상태의 의미
- state.json의 covered_through는 마지막 거래일이 아니다.
- 성공적으로 조회하고 저장한 요청 범위의 끝 날짜다.
- 원본과 조회 조건을 저장한 뒤 완료 날짜를 갱신한다.
- 재실행하면 조회 완료 날짜의 다음 날부터 진행한다.

## 실제 데이터로 확인한 결과
- 삼성전자 기존 결과를 활용하고 나머지 4종목에 총 48회 요청.
- 같은 기간 재실행 시 추가 요청 0회, 5종목 건너뛰기.
- 종목별 CSV 242행 × 8열, 전체 1,210행.
- 모든 종목의 날짜 범위: 2025-01-02~2025-12-30.
- 기본 품질 검사와 CSV 재읽기 비교 통과.

## 임시 상태로 확인한 결과
- 11월까지 완료한 상태에서 12월만 처리.
- 저장 성공 후 완료 날짜가 2025-12-31로 갱신됨.
- 재실행 시 추가 호출 없음.
- 실제 API 요청 0회, 실제 수집 상태와 CSV 변경 없음.
- 출력의 요청 1회는 대체한 연습용 함수의 실행 횟수다.

## 저장 위치
- 완료 상태: data/stock-day33/state.json
- 새로 수집한 원본·조회 조건: data/stock-day33/raw/
- 종목별 CSV: data/stock-day33/clean/
- 삼성전자 기존 CSV는 state.json에 기록된 32일차 파일을 활용한다.
- 실제 데이터와 토큰은 Git에 포함하지 않는다.
