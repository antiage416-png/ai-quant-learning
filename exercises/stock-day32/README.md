# 32일차 — 삼성전자 일별 시세 수집과 원본·정리본 저장

## 목적
한국투자증권 API로 한 종목의 시세를 수집하고,
원본 응답과 정리한 CSV를 분리해 저장·검증한다.

## 수집 기준
- 종목: 삼성전자 005930
- 제공처: 한국투자증권 Open API
- 시장: KRX
- 요청 기간: 2025-01-01~2025-12-31
- 단위: 일별
- 가격 기준: 수정주가

## 코드의 역할
| 파일 | 역할 |
|---|---|
| kis_auth.py | 토큰 발급·로컬 저장·유효기간 기준 재사용 |
| fetch_january.py | 1월 조회와 원본·조회 조건 저장 |
| clean_january.py | 1월 데이터를 공통 8개 열로 변환·검증 |
| fetch_year.py | 요청 사이 1초 대기하며 12개월 원본 수집 |
| clean_year.py | 완료 목록을 기준으로 월별 원본 병합·변환·검증 |

## 데이터 흐름
.env → 인증 토큰 → 월별 API 요청 → 원본과 조회 조건 저장
→ manifest.json 확인 → 자료형 변환·품질 검사 → CSV 저장·재읽기

## 저장 위치
- 코드·설명: exercises/stock-day32/
- 토큰: data/private/kis_token.json
- 원본·조회 조건·완료 목록: data/stock-day32/raw/
- 정리한 CSV: data/stock-day32/clean/
- .env와 data/는 Git 제외 대상이다.
- 키·앱시크릿·토큰 값을 코드·로그·문서에 기록하지 않는다.

## 확인한 결과
- 실제 토큰 발급과 저장된 토큰 재사용 확인.
- 1월: 18행 × 8열, 2025-01-02~2025-01-31.
- 연간: 12개월, 242행 × 8열, 2025-01-02~2025-12-30.
- 월별 조회 조건과 날짜 범위 검사 통과.
- 필수값 누락·중복·음수·가격 관계 검사 통과.
- CSV 재읽기 후 값·열 순서·자료형 비교 통과.
- 거래일 달력과의 대조는 아직 하지 않았다.

## 저장된 원본으로 변환 재실행

Ubuntu에서 가상환경을 활성화한 뒤 실행한다.
인터넷 요청 없이 최신 연간 수집 폴더를 읽으며,
같은 이름의 정리본 CSV가 있으면 덮어쓴다.

```bash
# 학습 저장소로 이동합니다.
cd /home/jaeho/ai-quant-learning

# 현재 터미널에서 기존 가상환경을 활성화합니다.
source .venv/bin/activate

# 원본을 다시 요청하지 않고 연간 CSV를 변환·검증합니다.
python /home/jaeho/ai-quant-learning/exercises/stock-day32/clean_year.py
```

## 구현 범위와 제한
- fetch_year.py는 실행할 때마다 12개월을 새로 조회한다.
- 증분 수집과 실패한 월만 재실행하는 기능은 아직 없다.
- 오류 발생 시 중단하고 이미 저장된 원본은 유지한다.
- manifest.json은 12개월 수집이 모두 성공한 경우에만 생성한다.
- clean_year.py는 최신 실행이 미완료이면 과거 성공 결과로 대체하지 않는다.
- 인증 실패 시 자동 토큰 재발급·요청 재시도는 구현하지 않았다.
- 수정주가 기준과 수집 시각은 월별 조회 조건 파일에 보존한다.
