## 48일차 — 현금·수량·비용 손계산 검증

### 목표와 진행 방식

작은 매수·매도 사례를 손으로 계산하고 Python 결과와 비교했다.
빈 파일에서 시작해 작은 코드 블록을 직접 붙여넣고,
실행 결과를 확인한 뒤 다음 계산을 추가했다.

입력 → 체결가격과 비용 계산 → 현금·보유수량 변경 →
최종 손익과 수익률 계산 → 손계산 검증 순서로 진행했다.

### 계산 조건

- 초기 자금: 10,000,000원
- 매수 기준 시가: 55,100원
- 매도 기준 시가: 53,300원
- 매수·매도 수수료율: 각각 0.0140527%
- 매도 세금: 기존 실습 조건인 2025년 0.15%
- 슬리피지: 매수 가격 +0.05%, 매도 가격 −0.05%
- 수수료·세금은 각각 계산한 뒤 원 미만을 버린다.
- 가격·현금은 Decimal로 소수 금액을 계산한다.
- 슬리피지는 체결가격에 포함하며 현금에서 다시 차감하지 않는다.
- 실제 시세 조회나 주문 없이 작은 예제만 계산한다.

### 수수료 때문에 수량을 줄이는 별도 예제

현금 10,000원과 슬리피지가 반영된 1주 가격 100원을 사용했다.

- 100주: 체결금액 10,000원 + 수수료 1원 = 10,001원으로 매수 불가.
- 99주: 체결금액 9,900원 + 수수료 1원 = 9,901원으로 매수 가능.
- 매수 후 남을 현금: 99원.
- while로 수량을 줄여 다시 계산하고, 매수 가능하면 break로 종료했다.
- 수량·필요 금액·잔액 검사가 모두 통과했다.

이 반복문은 별도 예제이며 앞의 1,000만원 계좌 계산에 통합하지 않았다.
0주만 가능한 경우 등의 일반적인 예외 처리는 이번에 검증하지 않았다.

### 배운 내용과 범위

- 현금과 보유수량은 거래에 따라 바뀌지만 초기 자금은 비교 기준으로 유지한다.
- 전체 자산은 현금과 보유 주식의 평가금액을 합한 값이다.
- 전량 매도한 경우에만 현금을 그대로 최종 자산으로 사용할 수 있다.
- 매수는 체결금액과 수수료를 현금에서 빼고 보유수량을 늘린다.
- 매도는 비용을 차감한 입금액을 현금에 더하고 보유수량을 줄인다.
- assert로 계산 결과가 손계산과 일치하는지 확인한다.
- 코드 실행과 일부 개념 확인을 완료했다. 독립적인 구현 숙련도는 별도 확인이 필요하다.
- 기존 전체 백테스트 코드를 변경한 것은 아니다.
