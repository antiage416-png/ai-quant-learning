## 39일차 — 이동평균 전략의 판단 조건과 체결 시점

### 목적

37일차에 계산한 5·20거래일 이동평균을 사용해
진입·청산 조건과 판단·체결 시점을 명확히 정의한다.

이 문서는 학습용 규칙이며 실제 주문을 실행하지 않는다.
수익성이 검증된 전략이라는 의미도 아니다.

### 입력 데이터

- 대상: 기존 실습의 삼성전자(005930)
- 지표 파일: data/stock-day37/005930_2025_indicators.csv
- 사용 지표: ma_5, ma_20
- 지표는 해당 거래일 종가를 포함해 계산된 값이다.
- 거래 시점은 날짜순으로 정렬된 다음 거래일을 기준으로 한다.

### 판단 시점과 체결 가정

- 당일 종가와 이동평균이 확정된 후 조건을 판단한다.
- 판단 결과에 따른 거래는 다음 거래일 시가에 체결된다고 가정한다.
- 당일 종가로 계산한 신호를 당일 종가에 체결하지 않는다.
- 다음 거래일은 다음 달력 날짜가 아니라 실제 데이터의 다음 거래일이다.
- 다음 거래일의 가격을 미리 보고 오늘의 판단을 바꾸지 않는다.

이 체결 방식은 모의 계산을 위한 가정이다.
실제 시가 체결을 보장하는 주문 방식까지 정의한 것은 아니다.

### 보유 상태

- 시작 상태는 미보유다.
- 미보유 또는 보유의 두 상태만 구분한다.
- 공매도와 보유 중 추가 매수는 하지 않는다.
- 보유 수량과 투자금은 이 문서에서 정하지 않는다.

### 진입·청산 조건

| 현재 상태 | 장 마감 후 조건 | 다음 거래일 행동 |
|---|---|---|
| 미보유 | ma_5 > ma_20 | 매수 |
| 미보유 | ma_5 <= ma_20 | 거래 없음 |
| 보유 | ma_5 < ma_20 | 매도 |
| 보유 | ma_5 >= ma_20 | 거래 없음 |

- 두 이동평균이 같으면 현재 상태를 유지한다.
- 이전 날의 교차 여부는 조건에 포함하지 않는다.
- 처음으로 두 이동평균이 유효해진 날에도 같은 규칙을 적용한다.
- 따라서 첫 유효 날짜에 ma_5 > ma_20이면 다음 거래일 매수 대상이다.

### 결측값과 예외

- 두 이동평균 중 하나라도 결측이면 그날 새 주문을 만들지 않는다.
- 초기 결측값을 0이나 미래 값으로 채우지 않는다.
- 예상하지 못한 중간 결측은 데이터 문제로 별도 확인한다.
- 신호만 발생했다고 보유 상태를 바꾸지 않는다.
- 가정한 체결이 일어난 시점에 보유 상태를 바꾼다.
- 예정된 거래일의 시가가 없거나 유효하지 않으면 임의 체결하지 않고 확인한다.

### 데이터 마지막 날

- 다음 거래일 데이터가 없으면 마지막 날 신호는 체결할 수 없다.
- 마지막 날이라고 임의로 강제 매도하지 않는다.
- 남아 있는 보유분은 마지막 종가로 평가하는 것으로 정의한다.

### 체결 가격 데이터

- 지표 CSV에는 시가가 없으므로 체결 가격을 종가로 대체하지 않는다.
- 구현할 때는 기존 정리 CSV의 open 열을 날짜와 종목코드로 연결한다.
- 정리 CSV: data/stock-day33/clean/005930_2025_clean.csv
- 체결 가격도 저장된 수정주가 요청 결과의 가격을 사용하는 모의 계산이다.
- 실제 주문 기록이나 실제 계좌를 재현하는 것은 아니다.

### 아직 정하지 않은 항목

- 투자금과 보유 수량
- 수수료·세금·슬리피지의 수치

결과 금액에 영향을 주는 가정은 구현 단계에서 먼저 설명하고 합의한다.
정하지 않은 비용을 임의로 0으로 넣고 순수익률이라고 부르지 않는다.
