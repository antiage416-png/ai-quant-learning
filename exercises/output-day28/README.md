# 28일차 — 수집 결과의 공통 출력 형식

## 목적
기존 명언·게시글 CSV를 같은 열 구조로 변환하고 원본 필드를 보존한다.

## 데이터 흐름
기존 CSV → 공통 열로 변환 → 결과 CSV 저장 → 다시 읽어 검증

## 공통 열
- record_type: quote 또는 post
- text: 명언 본문 또는 게시글 제목
- source_url: 출처 주소
- collected_at: 원본 수집 시각. 없으면 빈값
- original_data: 원래 행의 모든 필드를 보존한 JSON 문자열

## 실행
Ubuntu에서 프로젝트 가상환경을 활성화한 뒤 실행한다.
인터넷 요청은 없으며 기존 결과 CSV가 있으면 덮어쓴다.
원본 CSV와 DB는 변경하지 않는다.

```bash
# 학습 저장소로 이동합니다.
cd /home/jaeho/ai-quant-learning

# 현재 터미널에서 기존 가상환경을 활성화합니다.
source .venv/bin/activate

# 결과 CSV 두 개를 생성하고 저장 결과를 검증합니다.
python /home/jaeho/ai-quant-learning/exercises/output-day28/normalize_outputs.py
```

## 확인한 결과
| 항목 | 명언 | 게시글 |
|---|---:|---:|
| 원본 행·열 | 20 × 5 | 100 × 3 |
| 변환 행·열 | 20 × 5 | 100 × 5 |
| 수집 시각 빈값 | 0 | 100 |
| 원본 필드 보존 | 통과 | 통과 |

- 두 결과의 열 이름·순서와 저장 전후 행 수를 코드로 검증했다.
- original_data를 복원해 처음 읽은 원본 행들과 비교했다.
- 생성된 두 CSV를 VS Code에서 열어 확인했다.

## 현재 범위와 한계
- 기존 CSV를 변환했으며 실제 수집 코드에는 통합하지 않았다.
- 게시글에 없던 수집 시각은 임의로 생성하지 않았다.
- text는 자료 종류에 따라 본문 또는 제목이므로 의미를 구분해야 한다.
- 원본 보존 검사는 읽어 들인 필드 값 기준이며 파일 바이트 비교는 아니다.
