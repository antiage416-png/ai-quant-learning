## 43일차 — 주문·체결·현금·보유수량 기록 분리

### 학습 목표

주문 의도와 모의 체결 결과를 구분하고,
체결을 근거로 현금과 보유수량 변화를 추적한다.

### 네 기록의 역할

| 파일 | 역할 |
|---|---|
| orders.csv | 신호확인일·주문일·행동·수량 규칙 |
| fills.csv | 주문ID·모의 체결일·수량·가격·금액 |
| cash_ledger.csv | 시작 현금·현금 변화·마감 현금 |
| positions.csv | 시작 수량·수량 변화·마감 수량·주식 평가액 |

주문 기록만으로 현금이나 보유수량을 변경하지 않는다.
체결 결과를 계좌에 반영할 때 현금과 수량이 바뀐다.

### 기록 연결과 계산

- order_id는 주문을 구분한다.
- fills의 order_id로 대응 주문을 찾는다.
- 현금·보유수량 장부의 fill_id로 변화의 근거인 체결을 찾는다.
- 매수 체결: 현금 감소, 보유수량 증가
- 매도 체결: 현금 증가, 보유수량 감소
- 거래 없는 날: 변화량 0, 전날 마감 상태 유지
- 현금 잔액 = 초기자금 + 체결별 현금 변화의 누적 합
- 보유수량 = 체결별 수량 변화의 누적 합
- 자산가치 = 현금 + 보유수량 × 당일 종가

### 작은 예제 검증

초기자금 1,000만원으로 모의 체결 2건을 반영했다.

- 매수: 55,100원에 181주, 금액 9,973,100원
- 매수 후 현금: 26,900원
- 거래 없는 날에도 현금과 수량을 유지했다.
- 전량 매도: 53,300원에 181주, 금액 9,647,300원
- 최종 현금: 9,674,200원
- 최종 보유수량: 0주
- 주문·체결 연결 검사: 통과
- 현금·수량 손계산 비교: 통과
- 전날 마감·다음 날 시작 연결 검사: 통과

예제의 날짜와 거래는 장부 검증용이며 실제 교차 신호 결과와 별개다.

### 검증 범위와 이해 상태

- 기존 모의 결과를 사후 장부로 정리한 기록이다.
- 실제 증권사 주문이나 실제 체결 내역은 아니다.
- 이번 사례는 주문마다 한 번씩 전량 모의 체결된 결과다.
- 미체결·부분 체결까지 포함한 일반적인 주문 원장을 구현한 것은 아니다.
- 매수 수량은 모의 체결일 시가에서 계산한 기존 결과를 사용했다.
- 비용·배당·현금 이자는 아직 반영하지 않았다.
- 입력 연결과 계좌 대조는 수행했으며 출력 CSV 재읽기 검사는 별도로 수행하지 않았다.
- 실행과 검증은 완료했고 독립적인 설명·구현 능력은 별도 확인이 필요하다.
