# 30일차 — 한국투자증권 API 인증 설정 준비

## 목적
인증정보를 코드와 분리해 로컬에 보관하고,
값을 노출하지 않고 설정 상태를 검사한다.

## 준비 상태
- 실전용 APP Key와 APP Secret 발급 완료.
- 실제 값은 저장소 루트의 .env에 보관.
- .env의 Git 제외 규칙 적용과 미추적 상태 확인.
- 프로젝트 가상환경에 python-dotenv 1.2.3 설치.
- .env.example은 실제 키가 없는 공유용 설정 양식.

## 다른 환경에서 준비할 때
1. 기존 .env가 있는지 먼저 확인한다.
2. 없으면 .env.example을 참고해 로컬 .env를 만든다.
3. 자신의 키를 로컬 편집기에서 입력한다.
4. 파일 권한과 Git 제외 상태를 확인한다.
5. 가상환경에 python-dotenv를 설치하고 설정 검사를 실행한다.

## 설정 검사 실행
Ubuntu의 학습 저장소에서 실행한다.
아래 검사는 인터넷 요청이나 파일 변경 없이 .env를 읽는다.

```bash
# 학습 저장소로 이동합니다.
cd /home/jaeho/ai-quant-learning

# 현재 터미널에서 기존 가상환경을 활성화합니다.
source .venv/bin/activate

# 실제 값을 출력하지 않고 필수 설정을 검사합니다.
python /home/jaeho/ai-quant-learning/exercises/auth-day30/check_config.py
```

## 확인한 결과
- APP KEY: 입력 확인
- APP SECRET: 입력 확인
- 서버 주소: 실전 주소 일치
- 로컬 설정 검사: 통과
- 실제 API 인증: 아직 확인하지 않음

## 검사의 범위
- 설정값의 존재와 안내용 자리표시자 여부를 검사한다.
- 서버 주소가 지정한 실전 주소와 일치하는지 검사한다.
- 키의 유효성, 계좌 권한, 토큰 발급 성공을 검증한 것은 아니다.
- 시세 요청과 주문은 실행하지 않았다.

## 파일 관리
- .env: 실제 인증정보. 로컬에만 보관한다.
- .env.example: 값이 비어 있는 설정 양식. Git에 기록할 수 있다.
- 키·앱시크릿·토큰을 코드, 로그, 일지, 화면 공유에 포함하지 않는다.
