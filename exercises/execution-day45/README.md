# 7주차 45일차 — 누락 거래일·거래정지·체결 불가 처리 규칙

## 목표와 확정한 규칙

누락 거래일과 휴장일을 구분하고, 주문과 체결을 분리해 현금·보유수량을 관리한다.
사용자는 미체결 주문을 취소하는 방식을 선택했다.

| 상황 | 처리 규칙 |
|---|---|
| 주말·시장 휴장일 | 기준 거래일 달력에서 다음 거래일을 찾는다. |
| 거래일 자료 누락 | 계산을 중단하고 누락 원인을 확인한다. 다음 관측 행으로 주문일을 미루지 않는다. |
| 예정된 시가에 거래정지 또는 체결 불가가 확인됨 | 사유를 기록하고 미체결 취소로 주문을 종료한다. 다음 날 자동 재주문하지 않는다. |
| 거래정지 여부·자료가 미확인 | 확인된 거래정지로 간주하지 않고 계산을 중단한다. |
| 정상 상황의 시가가 결측·0·음수·무한대 | 가격 오류로 중단한다. 다른 가격으로 대체하지 않는다. |
| 비용을 포함해 한 주도 살 수 없음 | 기존 44일차와 같이 계산을 중단한다. |
| 체결 없음 | 현금·보유수량 변화, 체결 수수료·세금·슬리피지 환산액은 0이다. |
| 미보유 상태에서 데드크로스 | 매도 주문을 만들지 않는다. |
| 보유 상태에서 골든크로스 | 추가 매수 주문을 만들지 않는다. |
| 마지막 날 이후 거래일 자료가 없음 | 해당 신호를 체결하지 않는다. 마지막 보유분을 강제 매도하지 않는다. |

취소 이후 새 주문은 새로운 신호와 실제 모의 보유수량으로 판단한다.
취소된 주문이나 체결됐다고 가정한 상태를 다음 날로 넘기지 않는다.
매도 취소 후에는 주식을 계속 보유하므로 이후 가격 하락 위험도 남는다.
수량이 그대로여도 평가 자산가치는 종가에 따라 달라질 수 있다.

## 기존 자금·비용 조건

- 초기 자금 10,000,000원, 가용 현금 내 최대 정수 수량 매수, 전량 매도.
- 전날 마감 신호를 다음 거래일 시가에 처리한다.
- 매수·매도 수수료 각각 0.0140527%, 2025년 코스피 매도 세금 합계 0.15%.
- 슬리피지: 매수 가격 +0.05%, 매도 가격 -0.05%.
- 가격·현금은 소수 허용, 수수료·세금은 각각 체결 건마다 1원 미만 버림.
- 슬리피지는 체결가격에 이미 포함되므로 현금에서 다시 차감하지 않는다.
- 뱅키스 공개 기본요율을 고정 적용한 실습 가정이며 개인 우대 요율은 미확인이다.
- 배당·현금 이자·부분 체결은 반영하지 않았다.
- 비용 계산은 기존 `/home/jaeho/ai-quant-learning/exercises/costs-day44/check_costs.py`와 설정을 재사용한다.

## 작은 예제의 실제 결과

### 날짜 예제

- 기준 거래일은 2025-06-02, 2025-06-04, 2025-06-05다.
- 기존 기준에서 6월 3일은 휴장일이다.
- 6월 4일을 뺀 자료에서는 다음 관측 행이 5일이어도 누락 오류를 발견했다.
- 정상 날짜·누락·중복·역순·휴장일 포함·마지막 거래일 처리 검사가 통과했다.

### 매수 취소 예제

- 매수 취소 후 현금 10,000,000원·보유수량 0주를 유지했다.
- 다음 날 자동 재주문이 없었고, 이후 데드크로스에도 미보유 매도를 차단했다.
- 모의 체결 기록은 0건이었다.

### 매도 취소 예제

- 정상 매수 후 현금 20,511.45원·보유수량 181주였다.
- 매도 취소와 다음 날 주문 없음 상태에서 현금·수량을 유지했다.
- 이후 골든크로스에서는 이미 보유 중이므로 추가 매수를 하지 않았다.
- 그 다음 새 데드크로스로 전량 매도해 최종 현금 9,647,169.80원·0주가 됐다.
- 모의 체결 기록은 매수·매도 2건이었다.
- 미체결 잔액·비용 불변, 자동 재주문 없음, 상태별 주문 차단,
  새 신호 체결과 44일차 손계산 비교가 통과했다.
- 자료 미확인, 시가 0·결측·무한대에 대한 계산 중단 검사도 통과했다.

이 예제의 거래정지·체결 불가와 신호 순서는 인위적으로 만든 상황이다.
실제 삼성전자의 과거 거래정지 기록이나 이동평균 재계산 결과가 아니다.
