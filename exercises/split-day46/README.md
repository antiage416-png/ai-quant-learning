# 7주차 46일차 — 시간순 개발·검증·최종 평가 구간 분리

## 목표와 합의한 구간

개발·검증·최종 평가의 역할을 구분하고, 다섯 종목을 같은 날짜 경계로 분리한다.
사용자가 아래 구간을 선택했으며 날짜를 무작위로 섞지 않았다.

| 구간 | 첫 거래일 | 마지막 거래일 | 종목별 행 수 | 사용 목적 |
|---|---|---|---:|---|
| 개발 | 2025-01-02 | 2025-06-30 | 118 | 전략 규칙 개발·수정 |
| 검증 | 2025-07-01 | 2025-09-30 | 65 | 후보 규칙 확인·비교 |
| 최종 평가 | 2025-10-01 | 2025-12-30 | 59 | 규칙 확정 후 마지막 평가 |

합계는 종목별 242행이다. 대상은 005930, 000660, 005380, 035420, 055550이다.

## 실제 실행과 검증 결과

- 경계 확인용 날짜 6개를 구간별 2개씩 배정한 작은 예제가 통과했다.
- 경계 날짜 배정·중복 없는 분리·재결합 원본 복원·입력 보존 검사가 통과했다.
- 날짜 역순·중복·범위 밖 날짜·결측을 차단하는 검사가 통과했다.
- 실제 다섯 종목 모두 개발 118행·검증 65행·최종 평가 59행으로 분리됐다.
- 기존 34일차 거래일 기준 대조와 구간별 행 수 검사가 통과했다.
- 구간 간 중복 없음·전체 행 보존 검사가 통과했다.
- 저장 CSV 재읽기·재결합 원본 복원·원본 파일 보존·명세 재읽기가 통과했다.
- 첫 실행에서 CSV 15개와 분리 명세 1개, 총 16개를 새로 저장했다.
- 인터넷 요청·실제 주문·성과 계산은 없었다.

## 입력과 결과물

- 구간 설정과 분리 함수: `/home/jaeho/ai-quant-learning/exercises/split-day46/check_split.py`의 `PERIODS`, `split_by_period`.
- 실제 분리 코드: `/home/jaeho/ai-quant-learning/exercises/split-day46/build_splits.py`.
- 개발 CSV 5개: `/home/jaeho/ai-quant-learning/data/stock-day46/development/`.
- 검증 CSV 5개: `/home/jaeho/ai-quant-learning/data/stock-day46/validation/`.
- 최종 평가 CSV 5개: `/home/jaeho/ai-quant-learning/data/stock-day46/final_evaluation/`.
- 분리 명세: `/home/jaeho/ai-quant-learning/data/stock-day46/split_manifest.json`.

CSV는 입력의 모든 열과 문자열 값을 보존한다. 새 지표·수익률·주문은 계산하지 않았다.
명세에는 날짜 경계·파일별 행 수·원본 및 출력 파일의 SHA-256·자료 사용 범위를 저장했다.
SHA-256은 파일 내용 변경을 발견하는 비교값이며 파일 열람을 막는 잠금장치는 아니다.
동일한 결과로 재실행하면 기존 파일을 유지하고, 내용이 다른 기존 결과가 있으면 저장 전에 중단한다.


`between`은 시작일과 종료일을 포함해 구간 소속을 검사한다.
행별 소속 개수가 정확히 1인지 확인하고, `concat`으로 재결합해 원본과 비교한다.
거래일 자체의 누락은 분리 전에 45일차에서 검증한 달력 대조 함수로 확인한다.
34일차 달력은 당시 구성한 기준이며 KRX에서 직접 내려받은 달력 파일은 아니다.

## 자료 사용 규칙과 해석 범위

- 개발에서는 규칙을 만들고 수정하며, 검증에서는 후보를 비교한다.
- 최종 평가 자료는 규칙을 확정한 뒤 평가용으로 사용한다.
- 최종 평가 성과를 보고 규칙을 수정했다면 같은 구간을 독립적인 최종 평가로 다시 주장하지 않는다.
- 전체 폴더를 일괄 검색해 개발 자료에 최종 평가 파일을 함께 넣지 않도록 입력 경로를 명시한다.
- 파일 복사·날짜·행 수·해시·재읽기 검사는 자료 무결성 확인이다. 전략 성과를 비교한 것은 아니다.
- 이미 2025년 전체 그래프와 성과를 확인했다. 이번 최종 구간은 완전히 미관측인 독립 평가 자료가 아니다.
- 이번에는 구간 분리와 보관 절차를 학습했다. 새 자료를 이용한 독립적 성능 검증은 별도 과제다.
- 지표 계산에 필요한 과거 준비 자료와 평가 대상 날짜를 구분해야 한다. 구간을 나눴다는 이유로
  과거 이력을 버리거나 미래 자료를 사용해서는 안 된다. 구간별 지표·계좌 계산은 이번에 구현하지 않았다.
- 초기 자금·수량·비용·미체결 취소 규칙을 변경하지 않았다.
- 실행·검증 완료와 독립적인 이해·구현 능력은 구분한다.
- 다음은 47일차: 미래 데이터를 추가해도 이전 시점의 신호가 변하지 않는지 검사한다.
