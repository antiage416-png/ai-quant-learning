## 35일차 — 공급원 원본과 CSV 샘플 대조

### 목표

정리한 CSV의 값을 저장된 한국투자증권 원본 응답까지 추적하고,
출처·날짜 기준·검증 범위를 문서화한다.

### 데이터 출처와 기준

| 항목 | 내용 |
|---|---|
| 공급원 | 한국투자증권 Open API |
| API | 국내주식기간별시세(일·주·월·년) |
| 조회 경로 | /uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice |
| 시장 | KRX, 요청값 J |
| 주기 | 일봉, 요청값 D |
| 가격 요청 조건 | 수정주가, 요청값 0 |
| 요청 대상 기간 | 2025-01-01 ~ 2025-12-31 |
| CSV의 실제 날짜 범위 | 2025-01-02 ~ 2025-12-30 |
| 원본 수집일 | 2026-09-30 |
| 이번 대조일 | 2026-10-01 |

대상 기간은 가격이 나타내는 거래일 범위이고,
수집일은 API 응답을 받아 저장한 날이다.
파일명의 수집 시각에서 Z는 UTC를 뜻한다.
정확한 수집 시각은 각 원본에 대응하는 조회 조건 파일에서 확인한다.

공식 문서: https://apiportal.koreainvestment.com/

### 입력과 원본 연결

- 입력 CSV: data/stock-day33/clean/
- 종목: 삼성전자(005930), SK하이닉스(000660), 현대차(005380),
  NAVER(035420), 신한지주(055550)
- 삼성전자: 상태에 기록된 기존 CSV를 기준으로 32일차 연간 원본 폴더를 찾았다.
- 나머지 네 종목: 33일차 상태의 batches에 기록된 원본 경로를 사용했다.
- 각 표본의 CSV·원본 파일 경로는 sample_report.md에 기록했다.

### 표본 선택과 비교 방법

- 종목별 CSV를 날짜순으로 정렬하고 첫 행과 마지막 행을 선택했다.
- 5종목에서 2건씩, 총 10건을 비교했다.
- 선택된 날짜는 종목 모두 2025-01-02와 2025-12-30이었다.
- 같은 날짜의 원본 행을 찾아 시가·고가·저가·종가·거래량을 비교했다.
- 숫자는 Decimal로 변환해 값이 같은지 비교했다.
- 대응 원본이 없거나 여러 개라면 임의로 선택하지 않고 중단하도록 했다.

### 실행 방법

Ubuntu에서 기존 가상환경을 사용한다.
아래 Python 명령은 API 요청 없이 로컬 파일을 읽고 보고서를 저장한다.
원본 JSON과 CSV는 변경하지 않으며, 재실행하면 보고서를 갱신한다.

```bash
# 현재 터미널에서 기존 Python 가상환경을 활성화합니다.
source /home/jaeho/ai-quant-learning/.venv/bin/activate

# 표본 10건을 대조하고 sample_report.md를 저장합니다.
python /home/jaeho/ai-quant-learning/exercises/verify-day35/verify_samples.py
```

### 제약과 해석 범위

- 이번 검사는 저장된 공급원 응답에서 CSV로 값이 정확히 옮겨졌는지 확인한다.
- 다른 공급원과의 교차 검증이나 현재 API 재조회는 하지 않았다.
- 첫날과 마지막 날을 선택한 표본 검사이며 무작위 표본은 아니다.
- 표본 10건의 결과를 전체 1,210행의 값 검증 결과로 확대 해석하지 않는다.
- 공급원 데이터 자체의 정확성이나 실제 수정주가 보정 방식은 검증하지 않았다.
- 향후 공급원에서 과거 데이터를 수정하면 재조회 결과가 달라질 수 있다.
- 이 기록은 데이터의 공개·재배포 권한을 확인한 것이 아니다.
- 원본·CSV·인증 정보는 기존 Git 제외 규칙에 따라 로컬에 보관한다.
