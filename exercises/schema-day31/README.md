# 31일차 — 한국 주식 일별 데이터 구조 설계

## 목적
수집 결과의 열 이름과 자료형을 통일하고,
종목코드의 앞자리 0과 누락값을 올바르게 보존한다.

## 한 행의 의미
특정 종목의 특정 거래일에 대한 KRX 일별 시세 한 건.

## 기본 열

| 열 이름 | 의미 | pandas 자료형 |
|---|---|---|
| stock_code | 종목코드 | string |
| market | 조회 시장 | string |
| date | 거래일 | datetime64[ns] |
| open | 시가 | Int64 |
| high | 고가 | Int64 |
| low | 저가 | Int64 |
| close | 종가 | Int64 |
| volume | 거래량 | Int64 |

## 처리 기준
- 종목코드는 앞자리 0을 보존하는 6자리 문자열로 다룬다.
- market은 이번 실습에서 KRX로 고정한다.
- date는 거래일이며 수집 시각과 구분한다.
- 날짜는 pandas에서 날짜 자료형으로 다루고,
  CSV에는 YYYY-MM-DD 형식으로 저장한다.
- 가격과 거래량은 빈값을 표현할 수 있는 Int64를 사용한다.
- 누락값을 임의로 0으로 채우지 않는다.
- CSV는 자료형을 보존하지 않으므로 다시 읽을 때 자료형을 지정한다.

## 중복 기준
이번 데이터의 중복 판단 기준은 stock_code + market + date다.
가격 기준은 수정주가로 고정하고 원주가와 섞지 않는다.

## 출처와 수집 조건
기본 시세 열과 별도로 다음 정보를 함께 보관하도록 수집 단계에서 구현한다.
- 제공처
- 조회 기간
- 수정주가 여부
- 수집 시각

## 확인할 품질 기준
- 필수값 누락 여부
- 종목코드 형식과 날짜 변환 성공 여부
- 중복 기준에 해당하는 행 여부
- 가격과 거래량의 음수 여부
- 고가가 저가 이상인지 여부
- 시가와 종가가 저가~고가 범위 안에 있는지 여부

이상값은 원인을 확인하며 임의로 삭제하거나 수정하지 않는다.
