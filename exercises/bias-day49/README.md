## 49일차 — 생존편향과 백테스트 보고서

### 목표

생존 종목만 사후에 선택했을 때 분석 대상과 결과가 어떻게 달라지는지
이해하고, 기존 백테스트의 성과·검증 범위·한계를 보고서로 정리한다.

### 가상 예제 조건

- 같은 시작일에 세 종목에 각각 100만원을 투자한다.
- 같은 종료일까지 추가 매매·입출금·재조정은 없다.
- 비용과 배당은 제외한다.
- 종목별 기간 수익률은 +20%, +10%, −90%다.
- 세 번째 종목은 종료 시점에 상장폐지된 것으로 가정한다.
- −90%는 회수금까지 반영한 가상 손익이며 실제 상장폐지 수익률을 일반화한 값이 아니다.

### 실제 실행 결과

| 계산 대상 | 초기 자금 | 종료 자산 | 기간 수익률 |
|---|---:|---:|---:|
| 전체 세 종목 | 3,000,000원 | 2,400,000원 | −20% |
| 생존한 두 종목만 사후 선택 | 2,000,000원 | 2,300,000원 | +15% |

- 두 기간 수익률의 차이는 35%p다.
- 초기 투자금 비중으로 가중한 수익률이며, 동일 금액 투자라 산술평균과 일치한다.
- 여러 기간의 복리수익률을 구하는 기하평균이 아니다.
- 초기·종료 금액과 수익률의 손계산 비교가 통과했다.
- 정수 금액은 정확히 비교하고, float 수익률은 isclose로 작은 표현 오차를 허용했다.

### 해석과 실제 실습의 한계

종료 시점의 생존 여부로 과거 투자 대상을 고르면,
시작 당시 투자 가능했던 종목의 결과가 빠질 수 있다.

실제 자료 수집·통계 실습은 선택한 다섯 종목,
전략 성과 비교는 삼성전자 한 종목에 한정했다.
과거 전체 투자 가능 종목과 상장폐지 종목까지 포함한 자료를 구성하지 않았다.

생존편향을 제거했다고 주장하거나 결과를 시장 전체로 일반화하지 않는다.
가상 예제의 35%p를 실제 성과의 보정값으로 사용하지 않는다.
실제 생존편향의 크기나 방향을 측정한 것은 아니다.
