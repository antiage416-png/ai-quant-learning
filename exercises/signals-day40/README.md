## 40일차 — 교차 신호와 다음 거래일 모의 주문

### 목표

39일차에 정의한 골든크로스 진입·데드크로스 청산 규칙을 구현하고,
오늘 장 마감 후 관측한 정보와 다음 거래일 주문을 구분한다.

### 입력 데이터

- 지표: data/stock-day37/005930_2025_indicators.csv
- 가격: data/stock-day33/clean/005930_2025_clean.csv
- 대상: 삼성전자(005930), KRX, 2025년
- 지표와 가격을 종목코드·날짜로 연결했다.
- 양쪽 날짜 집합의 일치와 연결 키의 중복 여부를 검사했다.
- 모의 체결 가격은 정리 CSV의 open 열을 사용했다.

### 구현한 규칙

- 골든크로스:
  이전 거래일 ma_5 <= ma_20이고 오늘 ma_5 > ma_20인 경우
- 데드크로스:
  이전 거래일 ma_5 >= ma_20이고 오늘 ma_5 < ma_20인 경우
- 이전·오늘의 두 평균이 모두 유효할 때만 교차를 판단한다.
- 오늘 두 평균이 같으면 교차 신호가 없다.
- 처음 유효해진 날에 이미 ma_5 > ma_20이라는 이유만으로 진입하지 않는다.
- 초기 상태는 미보유다.
- 미보유 상태의 골든크로스는 다음 거래일 시가 모의 매수로 연결한다.
- 보유 상태의 데드크로스는 다음 거래일 시가 모의 매도로 연결한다.
- 추가 매수와 공매도는 하지 않는다.
- 모의 상태는 다음 거래일 시가에 체결됐다고 가정한 시점에 변경한다.
- 마지막 날에 보유하고 있어도 강제 청산하지 않는다.

### 시간 구분

- close_signal: 해당 거래일 장 마감 후 확인한 신호
- previous_signal: 이전 거래일 장 마감 후 확인한 신호
- open_order: 이전 신호를 바탕으로 오늘 시가에 배치한 모의 주문
- state_after_open: 오늘 시가의 모의 체결 처리 후 보유 상태

shift(1)은 이전 행의 값을 현재 행으로 가져온다.
신호에 적용하면 전날 마감 신호를 오늘 시가 주문 판단에 연결한다.
달력상 하루를 더하는 것이 아니라 데이터의 다음 거래일로 연결한다.

- 교차 발생일 검사: 통과

- 동률 처리 검사: 통과

실제 주문과 API 요청은 없다.

```bash

```

### 출력 파일

- 전체 기록: data/stock-day40/005930_2025_signals.csv
- 모의 주문 목록: data/stock-day40/005930_2025_orders.csv

모의 주문 목록에는 신호확인일, 모의주문일, 신호, 행동,
가정한 시가를 기록했다. 재실행하면 같은 출력 파일을 갱신한다.

### 범위와 한계

- 실행과 결과 확인은 완료했으며 이해·숙련도는 별도로 확인해야 한다.
