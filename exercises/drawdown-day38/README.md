## 38일차 — 보유 자산가치와 최대낙폭

### 목표와 계산 기준

자산가치와 누적 최고값으로 낙폭을 계산하고,
최종 수익률과 중간 하락 위험을 구분한다.

- 1주 기준 자산가치 = 저장된 종가
- 누적수익률 = 현재 자산가치 / 시작 자산가치 - 1
- 누적 최고값 = 해당 시점까지의 자산가치 최댓값
- 낙폭 = 현재 자산가치 / 누적 최고값 - 1
- 최대낙폭(MDD) = 낙폭의 최솟값

원본 CSV와 그래프를 바로 비교할 수 있도록 1주 기준을 사용한다.
낙폭은 음수로 표시한다.
미래의 최고값이 아니라 해당 시점까지의 최고값을 사용한다.

### 작은 예제의 실제 결과

자산가치 100 → 120 → 90 → 108 → 130을 사용했다.

- 최종 누적수익률: +30%
- 최대낙폭: -25%
- 누적 최고값·낙폭·최대낙폭 손계산 비교: 모두 통과

### 실제 데이터와 결과

- 입력: data/stock-day33/clean/005930_2025_clean.csv
- 대상: 삼성전자 KRX 일봉
- 기존 수집 조건: 수정주가 요청값 0
- 기간: 2025-01-02 ~ 2025-12-30
- 행 수: 242
- 계산 기준: 1주, 코드의 UNITS = 1
- 시작 자산가치: 53,400원
- 마지막 자산가치: 119,900원
- 최종 누적수익률: +124.5318%
- 최대낙폭: -14.6715%
- 최대낙폭 기준 고점 날짜: 2025-11-03
- 최대낙폭 저점 날짜: 2025-11-21
- 계산 검증: 통과
- CSV 재읽기 비교: 통과
- 1주 기준 PNG 그래프 생성 및 화면 확인: 완료

고정 배수를 10에서 1로 수정하면 자산가치 금액은 10분의 1이 되지만,
비율인 누적수익률과 낙폭, 해당 고점·저점 날짜는 변하지 않는다.

최대낙폭이 여러 번 발생하면 첫 번째 저점을 선택한다.
그 저점까지 동일한 기준 고점이 여러 번 있었다면 마지막 고점을 선택한다.

### 실행 환경과 방법

Ubuntu의 기존 Python 가상환경을 사용한다.
이번 실습에서 matplotlib 3.11.2를 가상환경에 설치했다.
그래프는 Agg 방식으로 창을 띄우지 않고 PNG로 저장한다.

```bash
# 현재 터미널에서 기존 가상환경을 활성화합니다.
source /home/jaeho/ai-quant-learning/.venv/bin/activate

# 작은 예제의 누적 최고값과 최대낙폭을 손계산으로 검증합니다.
# 파일 저장이나 API 요청은 없습니다.
python /home/jaeho/ai-quant-learning/exercises/drawdown-day38/check_drawdown.py

# 실제 데이터의 자산가치와 낙폭을 1주 기준으로 계산합니다.
# API 요청이나 입력 CSV 변경 없이 결과 CSV·PNG를 저장합니다.
# &&는 계산이 성공한 경우에만 다음 이미지 열기 명령을 실행합니다.
python /home/jaeho/ai-quant-learning/exercises/drawdown-day38/calculate_drawdown.py &&
code /home/jaeho/ai-quant-learning/data/stock-day38/005930_2025_drawdown.png
```

### 출력 파일

- data/stock-day38/005930_2025_drawdown.csv
- data/stock-day38/005930_2025_drawdown.png

재실행하면 같은 출력 파일을 갱신한다.
원본 입력 CSV는 변경하지 않는다.

- close: 원본 종가
- equity: 1주 기준 자산가치로, close와 같은 금액
- cumulative_return: 시작 자산가치 대비 누적수익률
- running_peak: 해당 시점까지의 최고 자산가치
- drawdown: 누적 최고값 대비 낙폭

CSV의 수익률과 낙폭은 소수 단위이며 화면에서는 퍼센트로 표시한다.

### 그래프 해석

- 위쪽 파란 선: 1주 기준 자산가치, 즉 저장된 종가
- 위쪽 주황 점선: 해당 시점까지의 최고 종가
- 위쪽 빨간 점: 최대낙폭의 기준 고점과 저점
- 아래쪽 빨간 영역: 누적 최고값 대비 낙폭
- 아래쪽 검은 점: 최대낙폭 발생 지점

최대낙폭은 연중 최저 가격이 아니라,
그때까지의 고점 대비 가장 깊은 하락을 나타낸다.

### 오류와 해결

- 처음 실행할 때 지정 경로에 calculate_drawdown.py가 없어
  파일을 찾을 수 없다는 오류가 발생했다.
- 계산이 실행되지 않아 PNG도 생성되지 않았고 이미지 열기가 실패했다.
- 계산 코드를 정확한 경로에 저장하고 다시 실행해 해결했다.
- 계산 성공 후에만 이미지를 열도록 &&로 두 명령을 연결했다.
- 처음에는 도우미가 임의로 종가에 10을 곱하는 가정을 추가해
  원본 종가와 그래프 금액이 달라 혼란이 발생했다.
- 사용자 지적 후 UNITS = 1로 수정하고 그래프 제목도 변경했다.
- 수정된 그래프가 원본 종가와 같은 금액 단위로 표시되는 것을 확인했다.
- 앞으로 보유 수량·투자금처럼 결과 숫자를 바꾸는 가정은
  임의로 추가하지 않고 먼저 설명하고 합의한다.

### 해석 범위와 이해 상태

- 저장된 수정주가 요청 결과의 종가를 그대로 사용하는 1주 기준 모형이다.
- 실제 계좌의 수량 변동·현금·배당·비용을 재현하지 않았다.
- 일별 종가 기준이며 장중 낙폭은 반영하지 않았다.
- 이번 관측 기간 이전의 고점은 사용하지 않았다.
- 최대낙폭은 과거 경로의 측정값이며 미래 손실의 상한이 아니다.
- 실행·검증·그래프 확인은 완료했다.
- 개념을 독립적으로 설명하거나 코드를 작성하는 능력은 별도 확인이 필요하다.
