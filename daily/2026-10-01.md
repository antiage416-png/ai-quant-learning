## 5주차 35일차 — 공급원 원본과 CSV 샘플 대조

### 오늘의 목표

CSV의 표본 값을 공급원 원본까지 추적하고,
출처·대상 기간·수집일·검증 제약을 기록한다.

### 실행한 내용

- 기존 가상환경을 활성화하고 학습 계획의 35일차 내용을 확인했다.
- 수집 상태에서 종목별 원본 연결 방식을 확인했다.
- 삼성전자는 32일차 결과 재사용, 나머지 네 종목은 33일차 월별 원본을 사용했다.
- verify_samples.py를 작성하고 실행했다.
- 종목별 첫 거래일과 마지막 거래일을 선택해 총 10건을 대조했다.
- 시가·고가·저가·종가·거래량을 원본 JSON과 비교했다.

### 실제 결과

- 선택 날짜: 5종목 모두 2025-01-02와 2025-12-30
- 표본 10건, 일치 10건, 불일치 0건
- sample_report.md 저장 완료
- API 요청이나 원본·CSV 변경 없이 검사했다.

### 학습 핵심과 이해 상태

- CSV와 원본은 필드 이름이 달라도 같은 항목을 연결해 비교할 수 있다.

- 표본 검사 결과를 전체 행의 값 검증으로 확대 해석하지 않는다.
- 실행과 결과 확인은 완료했다.
- 개념을 독립적으로 설명하거나 코드를 작성할 수 있는지는 별도로 확인해야 한다.

## 6주차 36일차 — 단순수익률과 누적수익률

### 오늘의 목표

단순수익률과 누적수익률을 계산하고, 손계산과 비교한 뒤
검증된 삼성전자 CSV에 적용한다.

### 실행과 실제 결과

- check_returns.py에서 가격 100 → 110 → 99를 사용했다.
- 일간수익률 +10%, -10%의 합은 0%였지만 누적수익률은 -1%였다.
- 손계산 및 누적수익률 두 계산법 비교가 모두 통과했다.
- calculate_returns.py로 삼성전자 종가의 수익률을 계산했다.
- 가격 242행에서 일간수익률 241개를 계산했다.
- 2025-01-02 종가 53,400원을 기준으로 삼았다.
- 2025-12-30 종가는 119,900원이었다.
- 기준일 종가 대비 누적수익률은 124.5318%였다.
- 누적수익률 두 계산법과 CSV 재읽기 비교가 통과했다.
- API 요청이나 입력 CSV 변경은 없었다.

### 결과물

- exercises/returns-day36/check_returns.py
- exercises/returns-day36/calculate_returns.py
- exercises/returns-day36/README.md
- 로컬 결과: data/stock-day36/005930_2025_returns.csv

### 학습 핵심과 이해 상태

- 단순수익률은 직전 가격 대비 변화율이다.
- 누적수익률은 기준 가격 대비 변화율이며 가격 배수를 곱해서도 계산한다.
- 첫날 단순수익률의 NaN은 이전 가격이 없기 때문이다.
- CSV에는 소수 단위, 화면에는 퍼센트 단위로 표시했다.
- 실행과 검증은 완료했고, 독립적인 설명·작성 능력은 별도 확인이 필요하다.

### 해석 범위

이번 누적수익률은 첫 거래일 종가부터 마지막 거래일 종가까지의
가격 변화율이다. 전년도 마지막 종가를 기준으로 한 연간 수익률이나
비용·현금 배당을 포함한 투자 수익률로 해석하지 않는다.

## 6주차 38일차 — 보유 자산가치와 최대낙폭

### 오늘의 목표

누적 최고 자산가치를 기준으로 낙폭과 최대낙폭을 계산하고,
그래프로 수익과 하락 과정을 함께 확인한다.

### 실행과 실제 결과

- 작은 예제 100 → 120 → 90 → 108 → 130을 사용했다.
- 최종 누적수익률 +30%, 최대낙폭 -25%를 확인했다.
- 손계산 비교 세 가지가 모두 통과했다.
- 기존 가상환경에 matplotlib 3.11.2를 설치했다.
- 삼성전자 종가를 그대로 사용하는 1주 기준 자산가치 모형으로 정리했다.
- 코드의 계산 기준은 UNITS = 1이다.
- 데이터는 242행이었다.
- 1주 기준 시작 자산가치는 53,400원, 마지막 자산가치는 119,900원이다.
- 최종 누적수익률은 +124.5318%, 최대낙폭은 -14.6715%였다.
- 최대낙폭의 기준 고점은 2025-11-03, 저점은 2025-11-21이었다.
- 계산 검증과 CSV 재읽기 비교가 통과했다.
- 1주 기준으로 수정된 자산가치·누적 최고값·낙폭 그래프를 열어 확인했다.
- 고정 배수를 10에서 1로 바꿔도 누적수익률과 낙폭은 변하지 않는다.

### 발생한 오류와 해결

- calculate_drawdown.py가 지정 경로에 없어 실행에 실패했다.
- 그 상태에서 PNG를 열어 이미지 로드도 실패했다.
- 계산 코드를 정확한 경로에 저장하고 재실행해 해결했다.
- &&로 계산 성공 시에만 이미지를 열도록 했다.
- 처음에는 도우미가 임의로 종가에 10을 곱하는 가정을 추가해
  원본 종가와 그래프 금액이 달라 혼란이 발생했다.
- 사용자 지적 후 UNITS = 1로 수정하고 그래프 제목도 변경했다.
- 수정된 그래프가 원본 종가와 같은 금액 단위로 표시되는 것을 확인했다.
- 원본 CSV의 종가는 변경하지 않았다.
- 앞으로 보유 수량·투자금처럼 결과 숫자를 바꾸는 가정은
  임의로 추가하지 않고 먼저 설명하고 합의한다.

### 학습 핵심과 이해 상태

- cummax는 미래가 아니라 해당 시점까지의 최고값을 구한다.
- 최종 수익률과 최대낙폭은 서로 다른 정보를 제공한다.
- 최대낙폭의 저점은 반드시 연중 최저 가격 날짜와 같지는 않다.
- 저장된 수정주가 요청 결과의 종가를 그대로 사용하는 1주 기준 모형이다.
- 실제 계좌의 수량 변동·현금·배당·비용을 재현하지 않았다.
- 일별 종가 기준이며 장중 낙폭은 반영하지 않았다.
- 이번 관측 기간 이전의 고점은 사용하지 않았다.
- 실행과 결과 확인은 완료했고, 이해·숙련도는 별도로 확인해야 한다.
