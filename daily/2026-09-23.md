## 2주차 8일차: HTML 선택자와 Network 관찰

### 요청과 응답 확인
- 요청 주소: https://example.com/
- 요청 방식: GET
- 처음에는 304 Not Modified 응답 확인
- Network의 Disable cache 체크 후 새로고침하니 200 응답 확인
- Response에서 HTML 본문과 제목·링크 태그 확인

### 200과 304의 차이
| 상태 코드 | 의미 | 응답 본문 |
|---|---|---|
| 200 OK | 요청에 성공해 내용을 전달 | 이번 GET 요청에서는 HTML 본문을 받음 |
| 304 Not Modified | 기존 캐시를 재사용할 수 있음 | 본문을 다시 보내지 않음 |

### 개발자 도구 탭의 역할
| 탭 | 확인하는 내용 |
|---|---|
| Elements | 브라우저가 구성한 현재 DOM 구조 |
| Headers | 요청 주소·방식, 응답 상태와 헤더 |
| Response | 해당 요청의 응답 내용 |

### 선택자 복습
- h1: h1 태그를 선택한다.
- p a: p 안에 있는 모든 깊이의 a 태그를 선택한다.
- a[href]: href 속성이 있는 a 태그를 선택한다.
- p > a는 p의 직접 자식인 a만 선택한다.
- p.a는 a라는 클래스를 가진 p를 선택한다.

## 2주차 9일차: CSS 선택자로 추출하고 누락 처리하기

### 실습
- articles.html에 연습용 기사 3개 작성.
- article.news-item 선택자로 기사 목록 추출.
- 각 기사 안에서 제목·날짜·링크를 개별적으로 검색.
- 인터넷 요청 없이 로컬 HTML로 실행.

### 사용한 선택자
| 선택자 | 대상 |
|---|---|
| article.news-item | news-item 클래스의 article |
| h2.title | title 클래스의 h2 |
| time.published | published 클래스의 time |
| h2.title a[href] | 제목 안에서 href 속성이 있는 a |

### 배운 내용
- enumerate(articles, start=1)은 기사와 1부터 시작하는 번호를 함께 제공한다.
- article.select_one()은 현재 기사 내부에서 검색한다.
- select_one()은 일치하는 요소가 없으면 None을 반환한다.
- 태그가 있는지 확인한 뒤 글자나 속성을 읽으면 누락으로 인한 오류를 방지할 수 있다.

### 실행 결과

- 두 번째 기사: 날짜 없음으로 처리.
- 세 번째 기사: 링크 없음으로 처리.
- 기사 3개 모두 오류 없이 처리 완료.
