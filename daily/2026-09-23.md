## 1주차 6일차: HTML 파싱과 CSV 저장

### 실습한 내용
- 가상환경에 beautifulsoup4와 pandas 설치
- 지난 실습에서 저장한 example.html 읽기
- BeautifulSoup으로 페이지 제목과 링크 추출
- pandas DataFrame으로 링크 글자와 주소 정리
- links.csv로 저장하고 다시 읽어 1행 × 2열 확인
- 저장한 CSV를 직접 열어 내용 확인

### 이해한 내용
- get_text(strip=True)는 태그 안의 글자를 가져오고 앞뒤 공백을 제거한다.
- a 태그의 href 속성에는 이동할 주소가 들어 있다.
- BeautifulSoup의 Tag 객체는 속성을 딕셔너리처럼 조회할 수 있다.
- 터미널의 DataFrame 출력은 열을 정렬한 텍스트다.
- CSV는 데이터를 저장하며 Excel의 색상·테두리 같은 서식은 저장하지 않는다.
