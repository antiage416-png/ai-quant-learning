### 배운 명령
- pwd: 현재 폴더의 전체 경로 확인
- ls, ls -l: 파일 목록과 상세 정보 확인
- cd: 작업 폴더 이동
- mkdir -p: 폴더 생성, 기존 폴더는 유지
- touch: 빈 파일 생성
- printf와 >: 글자를 파일에 저장. >는 기존 내용을 덮어씀
- cat: 파일 내용 출력
- cp -i: 파일 복사, 덮어쓰기 전 확인
- mv -i: 이름 변경 또는 이동, 덮어쓰기 전 확인
- less: 파일 읽기, q로 종료
