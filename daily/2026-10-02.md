## 6주차 41일차 — 교차 전략과 매수 후 보유 비교

### 오늘의 목표

두 전략을 같은 기간·자금 조건으로 비교하고,
자산가치와 최대낙폭을 함께 해석한다.

### 합의한 조건

- 초기자금은 사용자가 선택한 1,000만원이다.
- 현금으로 매수 가능한 최대 정수 수량을 사고 잔액을 유지한다.
- 매도 시 전량 매도한다.
- 비용·배당·현금 이자는 제외한다.
- 기간은 2025-01-02 ~ 2025-12-30이다.
- 시가에 거래하고 종가로 평가한다.
- 종료일에 강제 매도하지 않는다.

### 실행과 검증

- check_account.py로 현금·수량·자산가치의 손계산을 검증했다.
- 예제의 최종 자산 9,674,200원, 손익 -325,800원,
  수익률 -3.2580%를 확인했다.
- compare_strategies.py로 242행의 두 전략을 계산했다.
- 입력 연결·주문 시점 검사와 일별 CSV 재읽기 비교가 통과했다.
- plot_comparison.py로 비교 그래프를 저장하고 화면에서 확인했다.
- 실제 API 요청이나 주문은 없었다.

|---|---:|---:|
| 마지막 자산가치 | 16,625,400원 | 22,700,800원 |

### 이번 비교의 의미

골든크로스·데드크로스에 따라 매매하는 전략과
처음 매수해 종료일까지 보유하는 전략을 비교했다.

자산가치는 현금과 주식의 종가 평가액을 합친 금액이다.
위쪽 그래프는 자산가치의 경로, 아래쪽은 고점 대비 낙폭을 나타낸다.
낙폭의 가장 깊은 지점이 최대낙폭이다.

이번 조건에서는 매수 후 보유의 최종 자산이 높고 최대낙폭도 작았다.
다른 기간에도 같은 결과가 나온다고 판단하지는 않는다.

### 학습 핵심과 이해 상태

- 두 전략에 같은 초기자금·기간·가격·비용 처리 조건을 적용했다.
- 수익률의 분모와 낙폭의 시작 기준에 초기자금을 사용했다.
- 40일차 주문은 이미 다음 거래일에 배치돼 있어 다시 이동시키지 않았다.
- 현금 대기 중에는 자산가치가 일정하지만 이전 고점 대비 낙폭은 남을 수 있다.
- 처음 종가 기준 가격 수익률과 처음 시가 매수 후 계좌 수익률을 구분했다.
- 두 전략의 금액과 최대낙폭을 비교한다는 의미를 자신의 말로 확인했다.
- 독립적인 코드 작성·다른 데이터 적용 능력은 별도 확인이 필요하다.

## 6주차 42일차 — 통계 복습과 전략 결과 설명

### 실행과 실제 결과

- check_statistics.py로 설명용 수익률 4개의 통계를 계산했다.
- 양수 비율 50%, 평균 0%, 표본표준편차 9.1287%,
  누적수익률 -1.2475%를 확인했다.
- 두 배 수익률과 상관 +1, 음의 두 배와 상관 -1을 확인했다.
- 통계 손계산 비교가 통과했다.
- analyze_statistics.py로 실제 5종목의 통계를 계산했다.
- 가격 242개, 같은 날짜의 수익률 241개씩을 사용했다.
- 종목별 날짜 일치·수익률 결측 검사가 통과했다.
- statistics_report.md와 로컬 통계 CSV가 저장됐다.
- 실제 API 요청이나 입력 데이터 변경은 없었다.

### 실제 데이터에서 확인한 점

- 삼성전자와 SK하이닉스의 상승일 비율은 모두 53.9419%지만
  기간 수익률은 각각 +124.5318%, +280.2570%로 달랐다.
- NAVER의 상승일 비율은 46.0581%지만 기간 수익률은 +25.1290%였다.
- 일간수익률 표준편차는 SK하이닉스 3.4523%가 가장 크고,
  신한지주 1.8124%가 가장 작았다.
- 서로 다른 종목 사이에서 삼성전자–SK하이닉스의 상관계수
  0.5618이 가장 높았다.

### 학습 핵심

- 상승 빈도와 수익의 크기를 구분한다.
- 평균 수익률과 복리 누적수익률을 구분한다.
- 표준편차와 최대낙폭은 다른 정보를 제공한다.
- 상관관계는 같은 날짜의 수익률로 비교하며 인과관계로 해석하지 않는다.
- 가격 기준 수익률과 매수 가격·현금을 반영한 계좌 수익률을 구분한다.
- 관측한 통계를 미래 확률이나 성과로 단정하지 않는다.
