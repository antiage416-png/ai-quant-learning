## 5주차 30일차 — 한국투자증권 API 인증 설정 준비

### 진행한 내용
- 실전용 APP Key와 APP Secret을 발급받았다.
- 인증정보를 로컬 .env에 저장했다.
- .env의 Git 제외 규칙 적용과 미추적 상태를 확인했다.
- 가상환경에 python-dotenv 1.2.3을 설치했다.
- check_config.py로 필수 값과 실전 서버 주소를 검사했다.
- 공유용 .env.example과 실행 안내 README를 준비했다.

### 검증 결과
- 앱키·앱시크릿 입력 확인.
- 실전 서버 주소 일치.
- 로컬 설정 검사 통과.
- 검사 과정에서 실제 키 값을 출력하지 않았다.
- 실제 API 인증, 토큰 발급, 시세 요청은 아직 하지 않았다.

### 핵심 개념
- .env는 자동으로 Python에 적용되지 않으며 명시적으로 읽어야 한다.
- 실제 인증정보와 공유용 설정 양식을 구분한다.
- 로컬 설정 검사 통과와 실제 API 인증 성공은 다르다.

## 5주차 31일차 — 주가 데이터 구조와 자료형

### 진행한 내용
- 일별 주가 데이터의 기본 8개 열과 자료형을 설계했다.
- 한 행을 특정 종목·시장의 특정 거래일 시세로 정의했다.
- 수정주가 기준을 고정하고 중복 기준을
  stock_code + market + date로 정했다.
- check_schema.py에서 인위적인 예시 2행의 자료형을 변환했다.

### 확인한 결과
- 종목코드·시장: string
- 거래일: datetime64[ns]
- 가격·거래량: Int64
- 종목코드 앞자리 0, 정상 거래량, 누락값 보존 검사 모두 통과.

### 핵심 개념
- 종목코드는 계산할 숫자가 아닌 식별자다.
- Int64는 정수와 누락값을 함께 표현할 수 있다.
- 누락된 거래량과 실제 거래량 0은 구분해야 한다.

### 현재 범위
- 예시 데이터로 자료형과 값 보존을 검증했다.
- 실제 API 요청, CSV 저장·재읽기, 전체 품질 검사는 아직 하지 않았다.
