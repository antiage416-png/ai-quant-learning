## 4주차 27일차 — 한국 주식 데이터 제공처 비교

### 진행한 내용
- KRX·한국투자증권·키움 REST API의 제공 데이터, 이용 조건,
  호출 제한, 비용을 비교했다.
- 비교표와 공식 출처를 exercises/data-sources-day27/README.md에 저장했다.
- 한국투자증권을 우선 후보, KRX를 보조 후보, 키움을 비교 참고로 정리했다.

### 핵심 개념
- 요청당 데이터 건수와 초당 호출 횟수는 서로 다른 제한이다.
- 제공처별 필드 이름과 수정주가 조건을 확인하고 기준을 맞춰야 한다.
- API 무료 이용과 데이터 재배포 허용은 별개다.

### 확인 범위
- 문서 조사와 비교표 저장까지 진행했다.
- 실제 주가 API 호출은 하지 않았다.
- API 신청·인증키 발급 완료 여부는 확인하지 않았다.
- KRX·키움의 API 자체 이용료 등 미확인 사항은 비교표에 표시했다.

### 진행 방식에서 보완할 점
- 도우미의 안내 순서와 기록 위치가 바뀌어 혼란을 겪었다.
- 새날에는 저장소 이동과 가상환경 활성화부터 확인한다.
- 기존 AGENTS.md와 최신 재개 기록을 먼저 읽는다.
- 자료 조사는 도우미가 맡고 비교표로 설명한다.
- 설명 뒤에는 다음 행동과 완료 기준을 명확히 안내한다.

### 다음 진도

## 5주차 29일차 — 한국 주식 수집 범위 선정

### 진행한 내용
- 수집 대상 5개 종목을 정했다.
  - 삼성전자: 005930
  - SK하이닉스: 000660
  - 현대차: 005380
  - NAVER: 035420
  - 신한지주: 055550
- 제공처는 한국투자증권, 시장은 KRX로 정했다.
- 기간은 2025-01-01~2025-12-31, 일별 수정주가로 정했다.
- 수집 계획을 exercises/stock-plan-day29/README.md에 저장했다.
- 원하는 다른 종목은 이후 확장 실습에서 다루기로 했다.

### 살펴본 개념
- 종목코드는 앞자리 0을 유지하는 문자열로 다룬다.
- 달력 날짜와 거래일을 구분한다.
- 요청당 최대 100건 제한에 맞춰 기간을 나눠 수집해야 한다.
- 수정주가의 과거 값이 바뀔 수 있어 수집 시점과 조건을 기록한다.

### 현재 범위
- 수집 계획 작성까지 완료했다.
- 실제 주가 API 요청은 하지 않았다.
- API 서비스 신청·인증키 발급 여부는 아직 확인하지 않았다.
