## 9주차 59일차 — Dockerfile과 .dockerignore 작성 완료

- 전날 작성한 requirements.txt와 Dockerfile의 FROM·WORKDIR부터 이어갔다. 미커밋 기록을 보존했다.
- Docker 명령에서 WSL 통합 안내가 나왔다. 파일 작성은 진행했으며 연결 복구는 확인하지 않았다.
- 패키지 목록 복사·설치, 56일차 API와 52일차 의존 코드 복사 지시를 작성했다.
- EXPOSE·CMD를 터미널에서 실행해 command not found가 발생했다. Dockerfile에 적는 지시임을 설명하고 편집기에서 추가한 것을 확인했다.
- 사용자는 Docker 안에서 돌아갈 프로그램의 준비 사항과 실행 내용을 적는 과정이라고 설명했다.
- 프로젝트 최상위 .dockerignore에 Git·가상환경·캐시·데이터·환경 변수 파일 제외 규칙을 저장했다.
- 사용자는 data/를 제외해도 Ubuntu 원본은 남는다고 답했다. 빌드 입력에서 제외하고 실행 때 DB를 별도로 연결할 계획임을 설명했다.
- 저장된 설정 파일, COPY 원본 존재와 CMD JSON 형식을 확인했다. 실제 빌드·패키지 설치·컨테이너 실행은 아직 하지 않았다.
- README·handoff·계획표를 갱신했다. 59일차 작성 목표는 완료이며 독립적인 구현 숙련도와 실행 검증은 별도다.
- 전날 미커밋 기록과 이번 변경을 함께 수동 커밋·푸시하도록 안내한다. 푸시 완료는 아직 확인하지 않았다.
