## 2주차 10일차: 주소·날짜·공백 정리

### 실습한 내용
- normalize_article.py에서 예시 문자열을 정리했다.
- urljoin으로 /article/1을 https://example.com/article/1로 변환했다.
- strptime으로 날짜 문자열을 해석하고 strftime으로 YYYY-MM-DD 형식으로 변환했다.
- split과 join으로 연속 공백·줄바꿈·탭을 공백 하나로 정리했다.
- 인터넷 요청 없이 실행했다.

### 배운 점
- /로 시작하는 상대주소는 사이트의 루트 경로를 기준으로 한다.
- / 없이 시작하는 상대주소는 기준 페이지의 디렉터리를 기준으로 한다.
- / 유무에 따른 비교는 설명으로 이해했으며 별도 실행하지 않았다.
- strip은 앞뒤 공백만 제거한다.
- " ".join(text.split())은 내부 공백도 정리한다.

### 오류와 해결
- 실제 파일 이름이 nomalize_article.py여서 실행 경로와 달랐다.
- 파일 이름을 normalize_article.py로 수정한 뒤 정상 실행했다.

### 결과물
- exercises/normalize-day10/normalize_article.py

## 2주차 11일차: 이용 안내 확인과 페이지 이동

### 사전 확인
- 운영자의 안내에서 Quotes to Scrape가 크롤링 연습용 사이트임을 확인.
- /robots.txt 요청 결과는 HTTP 404.
- robots.txt가 없다는 사실만으로 모든 수집이 허용된다고 판단하지 않는다.

### 실습
- curl로 첫 페이지를 요청하고 page1.html로 저장.
- li.next a[href] 선택자로 Next 링크 추출.
- /page/2/를 urljoin으로 절대주소로 변환.
- urlopen으로 두 번째 페이지를 요청하고 page2.html로 저장.
- div.quote와 div.quote span.text로 명언 개수와 첫 명언 비교.

### 검증 결과
- 첫 페이지와 두 번째 페이지에서 각각 명언 10개 추출.
- 두 페이지의 첫 명언이 서로 다름을 확인.
- 이번 코드는 첫 페이지에서 두 번째 페이지까지 이동한다.
- 모든 페이지를 반복 수집하는 기능은 아직 구현하지 않았다.

### 결과물
- exercises/pagination-day11/page1.html
- exercises/pagination-day11/page2.html

## 2주차 12일차: 여러 페이지 결과 합치기와 중복 제거

### 실습
- 저장된 page1.html과 page2.html을 읽어 페이지별 요약을 만들었다.
- 페이지 URL, 명언 개수, 첫 명언을 하나의 DataFrame으로 합쳤다.
- 첫 페이지를 한 번 더 넣어 중복 상황을 재현했다.
- drop_duplicates(subset=["page_url"], keep="first")로 중복을 제거했다.
- 결과를 pages.csv로 저장하고 다시 읽어 검증했다.

### 검증 결과
- 중복 제거 전 3행, 제거 후 2행.
- 저장된 CSV는 2행 × 3열.
- 중복 URL 수는 0개.
- 인터넷 요청 없이 로컬 HTML로 실행했다.

### 배운 점
- 이번 데이터는 페이지 하나가 한 행이다.
- URL 문자열이 같은 행 중 첫 번째 행을 남겼다.
- 개별 명언을 페이지 URL만으로 중복 제거하면 서로 다른 명언도
  제거될 수 있으므로, 데이터의 한 행이 무엇인지 먼저 정해야 한다.

### 결과물
- exercises/dedup-day12/merge_pages.py
- exercises/dedup-day12/pages.csv

## 2주차 13일차: 함수 분리와 출처·시각 기록

### 실습
- fetch_html(): HTML 요청과 수집 시각 기록을 담당하도록 분리.
- parse_quotes(): HTML에서 명언과 작성자를 추출하도록 분리.
- 원문 페이지 주소와 UTC 기준 수집 시각을 결과에 포함.
- 제공되지 않은 발표 시각은 None으로 유지.
- 결과를 quotes.csv로 저장하고 다시 읽어 검증.

### 검증 결과
- CSV: 10행 × 5열.
- 원문 주소 누락: 0개.
- 수집 시각 누락: 0개.
- 발표 시각 누락: 10개.

### 배운 점
- 함수는 역할별로 코드를 나누고 결과를 return으로 전달한다.
- 발표 시각과 수집 시각은 서로 다른 정보다.
- 수집 시각은 응답 본문을 모두 받은 직후에 기록했다.
- None은 CSV에 빈칸으로 저장된다.
- 재실행하면 새 응답을 받으므로 수집 시각도 갱신된다.

### 결과물
- exercises/functions-day13/collect_quotes.py
- exercises/functions-day13/quotes.csv
